# Licensed music for Kaivor videos

Put audio files (mp3, wav, m4a) in this folder and add one row per track. Only tracks that are licensed for
commercial/brand use on TikTok and YouTube go here. Keep the licence page link so it can be checked later.

Good sources (sort by trending/popular): Pixabay Music (Pixabay Content License), YouTube Audio Library
(pick "no attribution required"), FreePD (CC0). Upload from a phone with github.com → this folder →
Add file → Upload files, or send the files in a chat with Claude.
